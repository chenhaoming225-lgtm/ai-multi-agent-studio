## Windows 特有坑（已解决）

- **httpx 502**：Python 的 httpx 默认 trust_env=True，会读注册表系统代理（Clash），把 localhost 请求塞给代理返回 502。解法：运行前设 `NO_PROXY=127.0.0.1,localhost`（run_company.py 已内置）
- **端口冲突**：8000 常被其他服务占用，网关用 **8010**
- **crewai 需要 litellm**：模型名带 - 走不了原生 provider，装 `pip install litellm` 到 studio venv
- **crewai 版本**：manager_agent 不能出现在 agents 列表；LLM 的 custom_llm_provider 参数不被接受（用 openai/ 前缀即可）
