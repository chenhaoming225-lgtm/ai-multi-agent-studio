# 股票快速概览

## 使用方式
输入股票名称或代码，返回：
1. 最新行情要点（价格/涨跌幅/成交额）
2. 关键支撑/阻力位
3. 近期消息面提示

## 输出模板
```
【股票概览】名称(代码)
价格 | 涨跌幅 | 成交额
支撑位: x / x   阻力位: x / x
消息面: ...
```

## 注意
- 本技能为演示版，接入真实行情源后可扩展分钟K线/盘口/资金流
